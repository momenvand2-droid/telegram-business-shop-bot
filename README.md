# Telegram Business Shop Bot v3

نسخه چندمحصولی:
- ۱ تا ۵۰ محصول در هر سفارش
- گرفتن تعداد و سپس نام هر محصول به‌صورت یکی‌یکی
- قیمت حدودی مستقل برای هر محصول بین ۷۹۹٬۰۰۰ تا ۲٬۰۰۰٬۰۰۰ تومان
- امکان اضافه‌کردن محصول تا سقف ۵۰
- محاسبه جمع حدودی نهایی
- دریافت سایزها، نام، شماره، آدرس و رسید
- ارسال سفارش و رسید برای مدیر
- اسکرین‌شات محصول باعث شروع جریان سفارش می‌شود و ربات برای جلوگیری از خطا، نام محصول را از مشتری می‌پرسد

## نسخه v4 — قیمت ثابت برای محصول تکراری

- قیمت هر محصول برای هر مشتری بعد از اولین بار در دیتابیس ذخیره می‌شود.
- اگر همان مشتری دوباره همان نام محصول را بگوید، همان قیمت قبلی استفاده می‌شود.
- عبارت‌هایی مثل «۵۰ تا هودی اسپایدرمن» به‌عنوان ۵۰ عدد از یک محصول ثبت می‌شوند؛ یک قیمت واحد دارند و جمع = تعداد × قیمت واحد.
- سقف هر سفارش ۵۰ عدد محصول است.
- برای پاک‌کردن قیمت‌های ذخیره‌شده یک مشتری: `/resetprices CHAT_ID`


## نسخه v5 — ارسال و پاسخ‌های فروشگاه

- فقط پست پیشتاز.
- هزینه ثابت ارسال برای کل سفارش ۱ تا ۵۰ عدد: ۱۱۲٬۰۰۰ تومان.
- ارسال/تحویل سفارش به پست: حدود ۳ تا ۵ روز کاری.
- زمان معمول رسیدن مرسوله: حدود ۸ تا ۱۲ روز.
- روزهای ارسال: شنبه تا پنجشنبه؛ جمعه ارسال نداریم.
- پاسخ‌های چندگانه برای روش ارسال، هزینه ارسال، تأخیر، روزهای ارسال و دلیل قیمت پایین.
- بعد از چند پیام نامفهوم پیاپی، پاسخ کوتاه «بله درسته ✅» داده می‌شود.

نکته: ادعاهای تجاری مثل اورجینال بودن همه کالاها یا داشتن قرارداد مستقیم با تولیدکننده فقط در صورتی به متن ربات اضافه شوند که واقعاً قابل تأیید باشند.
