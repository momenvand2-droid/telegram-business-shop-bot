# Boutique Telegram Business Bot

این نسخه برای اتصال به **Telegram Business > Chatbots / گفتگوی خودکار** ساخته شده است. مشتری به پی‌وی اکانت بیزینسی شما پیام می‌دهد و پاسخ از همان اکانت بیزینسی نمایش داده می‌شود؛ BotFather فقط برای ساخت رباتی است که پشت‌صحنه به اکانت Business متصل می‌شود.

## متغیرهای لازم

- `BOT_TOKEN` = توکن BotFather
- `ADMIN_ID` = آیدی عددی تلگرام ادمین

## اتصال در تلگرام

1. ربات را روی Railway یا سرور اجرا کنید.
2. در تلگرام وارد Settings شوید.
3. Telegram Business / Business را باز کنید.
4. Chatbots یا گفتگوی خودکار را باز کنید.
5. ربات BotFather خودتان را انتخاب و Connect کنید.
6. دسترسی پاسخ‌گویی به پیام‌ها را فعال کنید.
7. برای دکمه «حذف پیام شماره کارت»، دسترسی **Delete sent messages / حذف پیام‌های ارسالی** را هم فعال کنید.
8. در پی‌وی خود ربات دستور `/panel` را بفرستید تا پنل مدیریت باز شود.

## منطق پاسخ‌گویی

- پیام عادی اول مشتری: `بله تمامی محصولات ما موجوده ✅`
- پیام عادی بعدی: فرم سفارش + پیام ۲ + پیام تأیید نهایی
- سؤال قیمت: فقط `قیمت داخل پیج گذاشتیم 🌹`
- سؤال یا عبارت مرتبط با سایز: فقط راهنمای سایز کامل
- ویس/صدا: `لطفاً پیامتون رو تایپ کنید 🌹`
- عکس رسید: برای `ADMIN_ID` ارسال می‌شود و پیام تأیید نهایی برای مشتری می‌رود.
- `/panel`: تغییر پیام ۲، نمایش پیام ۲ و حذف پیام‌های شماره کارت ارسال‌شده.

## اجرای محلی

```bash
pip install -r requirements.txt
python bot.py
```

> برای Railway این برنامه با polling اجرا می‌شود و نیازی به دامنه یا webhook ندارد.
